QR Vault

Upload files into your own GitHub repo and get a named, scannable QR code for each one. Nothing is sent anywhere except to your repo — the whole thing runs in this page.

1

Connect your repo

Needs a fine-grained token with Contents: read/write on this one repo — not a broad token. Create one at github.com/settings/personal-access-tokens. The token is only kept in this browser's local storage, never uploaded anywhere.
i

How it works

Each file you add is committed straight to your repo via the GitHub API. Its QR code points to the file's raw GitHub URL, so scanning it opens the file directly. Rename and manage every QR code below — the list is saved in this browser, and you can export it as a backup file any time.
